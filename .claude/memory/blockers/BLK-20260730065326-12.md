# BLK-20260730065326-12 — Gain de vie/temps doublé en mode Chrono/Endurance

| Friction                                                                                                                                                                                                                 | Cause réelle                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Solution                                                                                                                                                                          | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| En mode Endurance, un gain de vie semblait survenir "au début du 3e niveau" plutôt qu'"après avoir terminé 3 niveaux" — décalage rapporté par Baptiste, non reproductible par simple lecture du code au premier passage. | `setLevelsCompleted((prev) => {...})` contenait des effets de bord (`setLives`, `addTime`) À L'INTÉRIEUR de l'updater fonctionnel. React StrictMode (actif dans `main.tsx`) invoque volontairement cet updater deux fois par appel pour détecter les impuretés — les effets de bord se déclenchaient donc deux fois par palier, pouvant accorder jusqu'à 2 vies d'un coup (souvent masqué par le plafond `maxLives`). Même mécanisme que GLRN-140 (déjà en mémoire globale), manifestation différente (bonus de jeu, pas analytics). | `next` calculé via un miroir par ref (`levelsCompletedRef`), `setLevelsCompleted` reçoit une valeur directe (pas de fonction), effets de bord sortis de tout updater fonctionnel. | résolu |
