# BLK-20260729171633-7 — shadcn CLI `add alert-dialog` a proposé d'écraser `button.tsx`

| Friction                                                                                                                                                                                                                                                                                                                                                                                     | Cause réelle                                                                                                                                                                                                                            | Solution                                                                                                                                                                                                                                                                                                                                 | Statut |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `pnpm dlx shadcn@latest add alert-dialog` (composant sans rapport direct avec `button.tsx`) a affiché un prompt "The file button.tsx already exists. Would you like to overwrite?" — confirmé par erreur via un `y` pipé en amont (mécanisme déjà connu, GLRN-195 : `--yes` ne saute pas ce prompt), écrasant la variante custom `icon-xl` de `buttonVariants` utilisée dans tout le projet. | Le CLI shadcn régénère parfois des dépendances transitives du composant demandé (ici `alert-dialog` importe `Button`) et propose de les réécrire dans leur version "stock", sans lien apparent avec le composant explicitement demandé. | Détecté immédiatement via `git diff --stat`/`git diff` sur `button.tsx` juste après la commande CLI (réflexe systématique après tout `shadcn add`), puis restauré avec `git checkout -- src/components/ui/button.tsx` avant tout autre changement. Le nouveau fichier `alert-dialog.tsx` a été conservé, seul `button.tsx` a été annulé. | résolu |
