# BLK-001 — Vercel Hobby = non-commercial + cap dur sans overage

**Friction** : Le plan Vercel Hobby (gratuit) interdit tout usage commercial (pub, achats in-app) et n'a pas d'overage payant — au-delà des limites, le déploiement est mis en pause jusqu'au cycle suivant

**Cause réelle** : Choix initial de rester sur Hobby tant que le jeu n'est pas monétisé, pour limiter les coûts au stade MVP

**Solution** : À trancher avant toute monétisation ou pic de trafic significatif : upgrade vers un plan payant Vercel
