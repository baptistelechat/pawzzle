# BLK-010 — `pnpm add ffmpeg-static` : binaire non téléchargé (build script ignoré)

| Friction                                                                                                                                                                                | Cause réelle                                                                                                                                              | Solution                                                                                                                                                   | Statut |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Après `pnpm add -D ffmpeg-static`, le binaire `ffmpeg.exe` était absent — `pnpm approve-builds` interactif impossible en session non-interactive, `pnpm rebuild` silencieux sans effet. | pnpm bloque par défaut les scripts postinstall pour raison de sécurité (voir GLRN-135) ; le package doit être explicitement autorisé au niveau workspace. | Ajout de `ffmpeg-static` à `onlyBuiltDependencies` dans `pnpm-workspace.yaml`, puis `pnpm install` — binaire téléchargé, testé (round-trip `.wav`→`.mp3`). | résolu |
