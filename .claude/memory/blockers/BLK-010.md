# BLK-010 — Icône du bouton d'installation iOS signalée toujours de taille différente

| Friction                                                                                                                                                                                                | Cause réelle                                                                                                                                                                                                                                                                                       | Solution                                                                                                                                                                                               | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| Après la centralisation `size-5` dans `button.tsx` ([BDR-031](../decisions/BDR-031.md)), Baptiste a signalé que l'icône du bouton d'install en mode iOS restait visuellement différente de ses voisins. | Le code (`Share`/`Download` sans classe explicite, résolu via `twMerge`) devrait produire un résultat identique dans les deux cas — cause la plus probable : service worker PWA (`registerType: autoUpdate`) servant encore l'ancien bundle JS en cache, non contourné par un simple rechargement. | Instructions données pour forcer la mise à jour du SW (DevTools → Appli → Service workers → "Mettre à jour lors de l'actualisation") ; non confirmé par Baptiste au moment de la fermeture de session. | ouvert |
