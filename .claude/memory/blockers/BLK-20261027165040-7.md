# BLK-20261027165040-7 — `pnpm add posthog-js` bloqué malgré `--trust-policy=none`

**Friction** : `pnpm add posthog-js` échoue en `ERR_PNPM_TRUST_DOWNGRADE` sur `@trickfilm400/rollup-plugin-off-main-thread` (sous-arbre `workbox-build`, déjà dans le lockfile). L'échappatoire documentée dans `pnpm-workspace.yaml` (`--trust-policy=none`), puis `npm_config_trust_policy=none`, donnent la même erreur — 3 tentatives.

**Cause réelle** : `none` n'est pas une valeur valide : pnpm accepte le flag sans erreur mais ignore la valeur. Seul `off` désactive le contrôle.

**Solution** : `pnpm add posthog-js --trust-policy=off` (la quarantaine `minimumReleaseAge` reste active). Commentaire de `pnpm-workspace.yaml` corrigé, ainsi que GLRN-234 et GBDR-007 (mémoire globale).
