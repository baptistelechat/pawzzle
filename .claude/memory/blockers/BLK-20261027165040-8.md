# BLK-20261027165040-8 — `VITE_POSTHOG_KEY` à ajouter à la main sur Vercel (Production)

**Friction** : Le connecteur MCP Vercel renvoie 403 sur la création d'une variable Production, et la CLI `vercel` n'est pas installée : la clé PostHog n'est pas configurée sur le projet `pawzzle`.

**Cause réelle** : Permissions du connecteur limitées pour les variables Production (voir GLRN-20261027165040-2, mémoire globale).

**Solution** : En attente — Baptiste ajoute `VITE_POSTHOG_KEY` dans le dashboard Vercel (Production seule) **avant** le merge vers `main`, sinon le build de prod part sans analytics. Vérifier ensuite les events dans PostHog *Live events* (`app = pawzzle`).
