# BLK-20260728232006-6 — `agent-browser open file:///$(pwd)/...` échoue en Git Bash sur Windows

| Friction                                                                                                                                                                                    | Cause réelle                                                                                                                                                                                                                                            | Solution                                                                                                                                  | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Un appel `agent-browser open "file:///$(pwd)/instagram/comment-on-sinstalle/slide-6.html"` a échoué avec `net::ERR_FILE_NOT_FOUND` dans une commande isolée, après régénération du slide 6. | `$(pwd)` seul dans Git Bash peut renvoyer un chemin POSIX-style (`/c/Users/...`) plutôt que le chemin Windows attendu (`C:/Users/...`) pour une navigation `file://` de Chrome — la boucle précédente utilisait `pwd -W`, cet appel isolé l'avait omis. | Remplacé par `f="$(pwd -W 2>/dev/null \|\| pwd)/instagram/comment-on-sinstalle/slide-6.html"` puis `open "file:///$f"` — succès immédiat. | résolu |
