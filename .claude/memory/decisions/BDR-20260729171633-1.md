# BDR-20260729171633-1 — Architecture modes de jeu : hook unique `useGameRun`, classic en no-op

| Décision                                                                                                                                                                                                                                                                                                                                                                          | Pourquoi                                                                                                                                                                                                                                                              | Alternatives considérées                                                                                                | Statut |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------ |
| Un seul hook `useGameRun(mode)` gère les 3 modes (Classique/Chrono/Endurance) plutôt que de brancher entre `useLevel()` nu et un hook de run selon le mode. `useLevel.ts` a été rendu configurable (`maxErrors`, `onInvalidPlacement`, `onValidPlacement`) pour rester le seul point d'entrée sous-jacent, avec un comportement no-op pour `classic` (`config.hasRun === false`). | Le mode ne change jamais pendant la durée de vie d'un `GameScreen` (remonté via `key={mode}`), mais appeler des hooks différents selon une prop reste interdit par `react-hooks/rules-of-hooks` — règle purement syntaxique qui ne sait pas que le composant remonte. | Brancher `mode === "classic" ? useLevel() : useGameRun(mode)` dans `GameScreen` — rejeté car viole les règles de hooks. | actif  |
