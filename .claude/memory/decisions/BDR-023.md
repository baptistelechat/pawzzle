# BDR-023 — Révélation de solution en cas d'échec : bordure + patte pleine vert saturé, sans halo, cases jamais tentées uniquement

| Décision                                                                                                                                                                                                                                                                                                                                                                                                   | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Alternatives considérées                                                                                                                                                                                                                                                                                     | Statut |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| En cas de défaite, chaque case correcte jamais tentée par le joueur affiche une patte pleine vert saturé (`emerald-600` clair / `emerald-400` sombre, `fill="currentColor"`) et une bordure de case assortie — même traitement visuel que les erreurs (bordure + icône colorée, aucun fond ajouté). Les cases déjà trouvées par le joueur gardent leur rendu normal, sans bordure ni patte supplémentaire. | Le token `--accent` du design system (vert doux) et un halo circulaire derrière l'icône ont d'abord été essayés, jugés peu lisibles par Baptiste — en particulier sur les cases de région déjà vertes de la grille. La bordure a aussi fui vers des cases déjà trouvées par erreur de logique (condition manquant le `!pawn`). La version finale reprend exactement le langage visuel déjà en place pour les erreurs, pour rester cohérente et lisible sur toutes les couleurs de région. | `text-accent` du design system (rejeté — pas assez saturé face aux régions pastel vertes). Halo `bg-background` derrière l'icône (rejeté — jugé inutile une fois la bordure de case en place). Teinte de fond sur toute la case (non retenu — casserait la cohérence avec le style "erreur", bordure seule). | actif  |
