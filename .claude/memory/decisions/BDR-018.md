# BDR-018 — Modèle d'interaction remplacé : tap = marqueur immédiat, appui long = animal

| Décision                                                                                                                                                                                                                                    | Pourquoi                                                                                                                                                                                                                                                                                                                                                          | Alternatives considérées                                                                                                                                                                                                                                                 | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| Le modèle [BDR-006](BDR-006.md) (tap retardé 300ms = marqueur, double-tap = animal) est remplacé : tap = marqueur posé immédiatement (sans délai), appui long (450ms) = pose de l'animal, glisser = pose en chaîne de marqueurs (inchangé). | Le double-tap chronométré posait puis retirait un marqueur si l'utilisateur n'appuyait pas assez vite pour valider la fenêtre — le 2e tap arrivait après expiration du timer et était traité comme un nouveau tap simple retirant le marqueur du 1er. Un geste par nature (tap vs appui maintenu) élimine cette fenêtre de temps à deviner (voir aussi GLRN-224). | Réduire la fenêtre 300ms → 180ms — testé, réduit le problème sans l'éliminer. Poser le marqueur immédiatement sans délai — réintroduit un flash visuel croix→patte sur un vrai double-tap rapide (le navigateur peint au moins une frame entre les deux taps physiques). | actif  |
