# BDR-045 — agent-browser fonctionne dans ce sandbox — sauf simulation de gestes

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                              | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                                                                | Alternatives considérées                                                                                                                                                                                                        | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `agent-browser` doit être utilisé pour la vérification navigateur (navigation, click, snapshot, screenshot, eval) sur ce projet — ça fonctionne de façon fiable. Seule la simulation de gestes (swipe tactile, drag souris, wheel) via CDP reste peu fiable et ne doit pas être utilisée pour valider ce type d'interaction : privilégier relecture de code + demande de vérification manuelle à Baptiste pour les gestes uniquement. | [BDR-027](../decisions/BDR-027.md) concluait à tort "agent-browser HS dans ce sandbox" de façon générale, sur la base d'un échec `open`/`doctor` un jour antérieur. Cette session a utilisé `agent-browser` avec succès sur 3 rounds de test distincts (dialogs, carrousel, captures d'écran) — seule la simulation bas-niveau de gestes (mouse wheel, mouse drag, touch) s'est montrée systématiquement non fiable, y compris via dispatch DOM direct. | Continuer à s'appuyer uniquement sur lint/build/vérification manuelle intégrale (statu quo BDR-027) — écarté, ça prive les sessions futures d'une vérification visuelle possible et fiable pour tout ce qui n'est pas un geste. | actif  |
