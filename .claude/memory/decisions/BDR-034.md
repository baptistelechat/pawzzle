# BDR-034 — Miroir par ref pour tout état lu-puis-écrit dans `togglePaw`

**Décision** : `errorsRef`/`placedRef` mirrorent `errors`/`placed` en synchrone, mis à jour au moment même de l'écriture.

**Pourquoi** : Deux appels à `togglePaw` déclenchés quasi simultanément (multi-touch, refs singleton de long-press) lisent le même state React figé avant re-render — `willLose`/`willWin`/la garde anti-doublon devaient tous rester corrects.

**Alternatives considérées** : `setState` fonctionnel seul (`setErrors(prev => ...)`) — écarté : `willLose`/`willWin` doivent être connus de façon synchrone avant `setState`, pour piloter haptique/son au même tick.
