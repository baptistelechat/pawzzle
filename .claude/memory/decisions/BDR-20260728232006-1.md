# BDR-20260728232006-1 — Stratégie contenu Instagram Pawzzle actée sans skill externe, 7 formats retenus via 3 rounds /rodin

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | Pourquoi                                                                                                                                                                                                                                                | Alternatives considérées                                                                                           | Statut |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------ |
| Après recherche de skills dédiés (Blotato, marcolang/instagram-carousel, etc. — voir `docs/social-content-skills-research.md`), décision de ne rien installer et de construire la stratégie à la main sur 3 rounds de propositions stress-testées par `/rodin`. 7 formats retenus (acquisition fonctionnel, acquisition+lore, acquisition comparaison, rétention série, rétention rejouabilité, rétention participatif, branding vague 3) avec plan de publication ordonné, cadence ~2 posts/semaine.
