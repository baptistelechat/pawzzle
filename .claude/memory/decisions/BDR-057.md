# BDR-057 — Forme de grille : masque booléen `active` sur bounding-box carrée

**Décision** : `Grid` gagne un champ `active: boolean[][]` : le plateau reste un bounding-box `size × size` (mêmes règles ligne/colonne/région/contact), certaines cases sont juste désactivées. `generateRegions` ne pioche/étend ses régions que parmi les cases actives, `countSolutions` saute les cases inactives, `Grid/index.tsx` rend un `<div>` inerte à leur place.

**Pourquoi** : Chaque ligne/colonne du bounding-box garde toujours au moins une case active (garanti par la formule du masque), donc les 3 règles existantes restent valables sans aucune modification — seul le sous-ensemble de cases jouables change. Pas de nouveau type de grille à faire cohabiter avec l'existant.

**Alternatives considérées** : Grille de forme réelle (liste de cases actives sans bounding-box carré) — écarté, aurait demandé de repenser les règles ligne/colonne/région plutôt que de simplement les restreindre.
