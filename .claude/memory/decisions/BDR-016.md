# BDR-016 — Pipeline sons Phase 4 : `public/sounds/` + noms = ID + normalisation `ffmpeg-static`

**Décision** : Sons stockés dans `public/sounds/`, nommés à l'identique de l'ID du son (`paw_correct.mp3`), format `.mp3` mono 44.1kHz. Script `pnpm sounds:normalize` (`ffmpeg-static` bundlé) convertit tout format brut déposé et réencode les mp3 déjà présents aux mêmes réglages.

**Pourquoi** : `public/` évite le hashing du bundler (inutile pour des SFX statiques) et simplifie le cache PWA ; `ffmpeg-static` évite d'exiger un ffmpeg système installé pour un script d'outillage ponctuel.

**Alternatives considérées** : `src/assets/` bundlé (écarté, aucun bénéfice de hashing pour ce cas) ; ffmpeg système (écarté, dépendance d'installation manuelle sur la machine de Baptiste).
