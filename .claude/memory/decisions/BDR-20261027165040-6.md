# BDR-20261027165040-6 — og:image template Logo + sous-titre « Chacun son quartier, zéro voisin collé. »

**Décision** : og:image statique `public/og-image.png` (1200×630) sur le template ogimagecn « Logo » recoloré « Atelier Feutrine » (fond `#fff8f0`, halo primaire, logo chat, wordmark Fredoka, sous-titre IBM Plex Sans), rendue one-shot par Satori + resvg hors repo. Meta OG/Twitter dans `index.html` en URL absolue `https://pawzzle-game.vercel.app/`. Le sous-titre sert aussi de `<title>` et de base au slogan.

**Pourquoi** : Projet déjà brandé : point d'entrée rapide de `brand-creator` (étape 9), sans refaire direction ni logo. Le template Logo reste lisible en miniature de partage. Le sous-titre reprend le lore du village (quartier = couleur, zéro contact) sans nombre fixe de chats ni thème feutrine.

**Alternatives considérées** : Templates Grid/Showcase avec une vraie grille 5×5 (plus explicites sur le gameplay) et Simple/Editorial/Shiori — moodboard `docs/design/og-image-moodboard.html`. Sous-titres écartés : « Le puzzle logique qui ronronne », « Pas un chat ne se touche. », « Place les chats. Évite les voisins. ».
