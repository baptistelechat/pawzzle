# BDR-20260729171633-2 — Chrono/Endurance : pool de vies de run partagé, chiffres actés

| Décision                                                                                                                                                                                                                                                                                                                                                                                                       | Pourquoi                                                                                                                                              | Alternatives considérées                                                                                                                                                             | Statut |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| Chrono et Endurance partagent un seul pool de vies pour toute la run (pas par niveau) ; chaque erreur individuelle consomme 1 vie. Chrono : 60s départ, +5s par chat trouvé, +10s par niveau réussi, +20s tous les 5 niveaux réussis. Endurance : 3 vies départ, +1 vie tous les 5 niveaux réussis, plafond 3. Le mode Classique garde son budget historique de 3 erreurs par niveau (`MAX_ERRORS`), inchangé. | Actée avec Baptiste via AskUserQuestion — les 2 nouveaux modes introduisent une notion de "run" (session multi-niveaux) qui n'existait pas jusque-là. | Vie de run consommée seulement quand un niveau entier est raté (3 erreurs) plutôt qu'à chaque erreur individuelle — écartée par Baptiste au profit d'un pool consommé immédiatement. | actif  |
