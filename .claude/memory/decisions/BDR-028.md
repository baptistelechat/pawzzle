# BDR-028 — Boutons Réglages/Règles flanquant le bouton d'action principal

**Décision** : Boutons `SettingsDialog`/`RulesDialog` déplacés du header (à côté du titre) vers une rangée unique flanquant le bouton "Nouvelle partie"/"Rejouer", en `size="icon-xl"` avec icônes forcées à `size-5` pour matcher les icônes du bouton d'action

**Pourquoi** : Baptiste jugeait le placement à côté du titre pas convaincant ; regrouper les 3 boutons dans une seule rangée sous la grille aligne visuellement toutes les icônes sur la même hauteur/taille

**Alternatives considérées** : Rester à côté du titre (déjà tenté plusieurs fois le même jour, cf. journal du 2026-07-25)
