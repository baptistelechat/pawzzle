# BDR-053 — `MAX_ATTEMPTS` du générateur relevé de 1000 à 5000

| Décision                                                                                             | Pourquoi                                                                                                                                                                                                                                                                                                                       | Alternatives considérées                                                                                                                                        | Statut |
| ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Le garde-fou anti-boucle infinie du générateur (`generator.ts`) passe de 1000 à 5000 tentatives max. | Mesuré empiriquement hors application (script Node isolé) : le 10×10 échouait parfois avant de trouver une solution unique avec 1000 tentatives ; sur un échantillon de 50 générations, le pire cas observé était ~2100 tentatives (jusqu'à ~2.8s). 5000 laisse une marge confortable sans bloquer indéfiniment le Web Worker. | Améliorer l'algorithme de génération de régions pour converger plus vite — écarté, hors scope de cette session (juste débloquer le 10×10 avec l'algo existant). | actif  |
