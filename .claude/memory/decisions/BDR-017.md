# BDR-017 — Architecture son : Web Audio API pour les SFX, `<audio loop>` natif pour l'ambiance

| Décision                                                                                                                                                                                                                                                                                                                                            | Pourquoi                                                                                                                                                                                                                                                                                                                           | Alternatives considérées                                                                                                                                                                                                                         | Statut |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| SFX one-shot (`marker_add`, `paw_correct`, etc.) joués via Web Audio API (buffer décodé + `GainNode` par-son + `GainNode` maître + `DynamicsCompressorNode`) ; musique d'ambiance jouée via `<audio loop>` natif, un seul flux long-format. Déverrouillage (resume du contexte / 1er `play()`) exclusivement sur `pointerup`, jamais `pointerdown`. | Les SFX courts doivent pouvoir se superposer (ex. `drag_paint_tick` répété pendant un glisser) et avoir un gain réglable individuellement — le Web Audio API le permet nativement. L'ambiance est un flux unique continu sans besoin de superposition : `<audio loop>` natif suffit, plus simple qu'un buffer bouclé en Web Audio. | Tout en Web Audio (buffer + boucle manuelle pour l'ambiance aussi) — rejeté, complexité inutile pour un flux unique. Tout en `<audio>` (un élément par SFX) — rejeté, pas de contrôle de gain individuel fiable ni de garantie de superposition. | actif  |
