# BDR-001 — Stack : Vite+React+TS, Supabase, PWA, Vercel Hobby

**Décision** : Vite+React+TS en SPA pure, Supabase (auth/DB/edge functions), distribution PWA, hébergement Vercel Hobby

**Pourquoi** : Le jeu est un état d'application sans besoin de SSR ; PWA évite les contraintes App Store (commission, review) ; Supabase free tier largement suffisant pour un lancement

**Alternatives considérées** : App native (rejetée : contraintes stores) ; SSR (rejeté : pas de besoin SEO côté jeu)
