# BDR-20260729171633-3 — Actions qui abandonnent une run protégées par confirmation, reset par remount

| Décision                                                                                                                                                                                                                                                                                                                                              | Pourquoi                                                                                                                                                                                                                                                                                                                             | Alternatives considérées                                                                                                                 | Statut |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Quitter (bouton Accueil) ou relancer ("Nouvelle partie" en cours de niveau) une run Chrono/Endurance active ouvre une `AlertDialog` de confirmation (composant shadcn ajouté au projet). La remise à zéro d'une run se fait en incrémentant une clé de remount (`runKey`) côté `App.tsx`, pas via une fonction `resetRun()` dédiée dans `useGameRun`. | Perdre une run en cours (niveaux/vies/temps) est une action irréversible (cf. GLRN-110, guard UX bloquant obligatoire). Le remount via `key` réutilise le pattern déjà établi pour `Grid`/`levelId` ([BDR-015](BDR-015.md)) plutôt que de dupliquer la logique de remise à zéro de `useLevel`+`useGameRun` dans une fonction dédiée. | `resetRun()` explicite dans le hook, réinitialisant chaque state à la main — écarté, plus de code pour un résultat identique au remount. | actif  |
