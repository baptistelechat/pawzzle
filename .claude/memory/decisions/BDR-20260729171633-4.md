# BDR-20260729171633-4 — Ton non-agressif en fin de run, noms de mode génériques pour l'instant

| Le récap de fin de run (Chrono/Endurance) évite tout texte ou son perçu comme agressif ("Game Over"/"Perdu"/"Échec") — copy positive centrée sur l'accompli ("X niveaux complétés").
