# BDR-049 — `finalFocus` désactivé uniquement pour une fermeture tactile

| Décision                                                                                                                                                                                                       | Pourquoi                                                                                                                                                                                                                                                                                                         | Alternatives considérées                                                                                                                               | Statut |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| `finalFocus={(closeType) => closeType !== "touch"}` posé par défaut sur `DialogContent` (`ui/dialog.tsx`) — le focus ne revient sur le bouton déclencheur qu'à la fermeture clavier/souris, jamais au tactile. | Base UI ramène le focus sur le déclencheur à la fermeture (nécessaire au clavier, a11y) — mais reposer le focus sur un petit bouton juste après une interaction tactile déclenche un zoom natif d'Android Chrome (bug connu, voir GLRN-249). Seul le tactile est désactivé pour ne pas sacrifier l'a11y clavier. | `finalFocus={false}` global (écarté, casse le retour de focus clavier). Agrandir les boutons déclencheurs (écarté, sans rapport avec la cause réelle). | actif  |
