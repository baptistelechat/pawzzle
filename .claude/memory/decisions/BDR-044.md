# BDR-044 — Autoplay carrousel : pause sur interaction + reprise après 6s d'inactivité

| Décision                                                                                                                                                                                                                                                                                | Pourquoi                                                                                                                                                                   | Alternatives considérées                                                                      | Statut |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- | ------ |
| Le carrousel de règles avance automatiquement toutes les 4s en boucle continue. Toute interaction manuelle (swipe, flèche, point, bouton pause) coupe l'autoplay ; il reprend seul après 6s sans nouvelle interaction. Bouton play/pause + compteur `n/m` en bas à droite du carrousel. | Demande explicite de Baptiste ("lecture auto" + "relance après inactivité"). La reprise automatique évite qu'un utilisateur reste bloqué en pause sans s'en rendre compte. | Pause permanente jusqu'à clic explicite sur play — écarté, contraire à la demande de reprise. | actif  |
