# BDR-20260730065326-2 — Fin de run affiche la solution avant le récap

| Décision                                                                                                                                                                                                                                                                   | Pourquoi                                                                                                               | Alternatives considérées                                                                                                                | Statut |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Quand une run Chrono/Endurance se termine (vies/temps épuisés), la grille reste affichée avec la solution révélée (comme le "lost" du mode Classique) et le bouton principal devient "Résultats" ; ce n'est qu'au clic que l'écran bascule sur le récap (`GameOverPanel`). | Demande explicite de Baptiste — voir la solution du niveau en cours avant de passer au bilan, comme en mode Classique. | Bascule immédiate sur `GameOverPanel` dès la fin de run (comportement initial) — écartée, ne laissait pas le temps de voir la solution. | actif  |
