# BDR-043 — Carrousel de règles : CSS natif, "Comment jouer" en section fixe hors carrousel

| Décision                                                                                                                                                                                                                                                                                                                     | Pourquoi                                                                                                                                                                                                                                                                                                                 | Alternatives considérées                                                                                                                                        | Statut |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Remplacer la liste verticale des 3 règles + `ScrollArea` par un carrousel horizontal en CSS natif (`overflow-x-auto` + `snap-x`/`snap-mandatory`), flèches gauche/droite flanquant la carte, points sous la carte. "Comment jouer ?" reste une section fixe sous le carrousel, toujours visible, jamais une carte swipeable. | Baptiste voulait naviguer entre les règles au swipe/flèches ET voir "Comment jouer" sans scroller. Première itération l'avait mis en 4ème carte du carrousel — corrigé après retour explicite : "voir de n'importe où" signifiait élément fixe, pas accessible par navigation (voir [LRN-032](../learnings/LRN-032.md)). | Composant `Carousel` shadcn/ui (embarque `embla-carousel-react`) — écarté, aucune dépendance ajoutée nécessaire pour un besoin aussi simple (CSS natif suffit). | actif  |

## Références

- [LRN-030](../learnings/LRN-030.md) — `snap-always` empêche un swipe rapide de sauter plusieurs cartes
- [LRN-032](../learnings/LRN-032.md) — "Voir X depuis n'importe où" = élément fixe, pas une carte de plus
