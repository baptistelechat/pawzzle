# BDR-066 — Badge de difficulté remplacé par 3 icônes Flame fill/outline

**Décision** : `DifficultyBadge` (composant shadcn `Badge`) remplacé par `DifficultyFire` : 3 icônes `Flame` (lucide-react), remplies (`fill-primary`) selon le niveau (1 pour easy, 2 medium, 3 hard), outline sinon — même langage visuel que `HeartsRow` (cœurs pleins/cassés).

**Pourquoi** : Demande explicite de Baptiste, pour une cohérence visuelle avec le reste de la rangée de statut (cœurs de vie).

**Alternatives considérées** : Garder le badge texte shadcn (écarté, demande explicite).
