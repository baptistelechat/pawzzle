# BDR-20261027165040-5 — Analytics Pawzzle : PostHog `memory` + compteurs locaux d'adoption

**Décision** : PostHog dans le projet partagé « Ifecho » (EU), même recette que les autres apps : `register({ app: "pawzzle", app_version, display_mode, visit_number, days_since_first_visit })`, `persistence: "memory"`, `autocapture: false`, Session Replay désactivé, `capture_exceptions: true`, SDK chargé en `import()` différé (~100 kB gzip hors bundle principal). Catalogue fermé de 19 events typés dans `src/lib/analytics.ts` (cycle niveau/run, réglages, ambiance, PWA). Envoi bloqué en dev, sur localhost et sur IP locale ; `VITE_POSTHOG_KEY` définie sur Vercel en **Production uniquement**.

**Pourquoi** : `memory` évite tout cookie/identifiant stocké, donc pas de bandeau RGPD, mais rend chaque visite anonyme : les compteurs `pawzzle:visits` (première visite, nombre de visites, niveaux à vie), sans identifiant, restaurent la mesure nouveaux vs revenants et l'engagement, par appareil. Scope Production seule : les previews Vercel sont buildées en prod et sur de vrais domaines, le code ne peut pas les distinguer sans `VERCEL_ENV`.

**Alternatives considérées** : `persistence: "localStorage"` pour une vraie rétention par personne — écartée (identifiant persistant = consentement requis). Variable aussi sur Preview + super-propriété `environment` — écartée pour la bêta, double filtre à penser sur chaque insight.
