# BDR-013 — Haptique de pose correcte = même pattern renforcé que la victoire

| Décision                                                                                                                                                                                                                                                                | Pourquoi                                                                                                                                                                                                                                                | Alternatives considérées                                                                                                                                                        | Statut |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Chaque pose correcte d'un pion (pas seulement la victoire finale du niveau) déclenche le même pattern haptique custom renforcé (`SUCCESS_HAPTIC`, 3 pulsations montant jusqu'à intensité max) — pas de version "light" intermédiaire pour les poses en cours de partie. | Baptiste a explicitement demandé de reprendre "la même animation que pour finish" et de l'appliquer à "succès animal" (chaque pose correcte) plutôt que de garder le preset `selection` (trop faible, 8ms/0.3 intensité) pour les poses intermédiaires. | Un pattern intermédiaire dédié entre `selection` et le pattern de victoire — écarté, Baptiste voulait explicitement la réutilisation à l'identique, pas une nouvelle gradation. | actif  |
