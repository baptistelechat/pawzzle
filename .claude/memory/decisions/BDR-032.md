# BDR-032 — Clé localStorage `pawzzle:settings` reste sans version

| Décision                                                              | Pourquoi                                                                                                                                                                                                                                  | Alternatives considérées                                                                                                                           | Statut |
| --------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Clé `pawzzle:settings` conservée sans suffixe `:v1`, pas de migration | react-doctor (`client-localstorage-no-version`) recommandait le versioning ; le merge défensif déjà en place (`{...DEFAULT_SETTINGS, ...JSON.parse(raw)}` + `try/catch`) couvre déjà les cas additifs (champ ajouté/retiré/JSON corrompu) | Clé versionnée `pawzzle:settings:v1` — testée puis reverted, invalidait les données déjà stockées sous l'ancienne clé sans bénéfice pour ce projet | actif  |
