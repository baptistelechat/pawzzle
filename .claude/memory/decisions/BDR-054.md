# BDR-054 — Infra de test retirée entièrement

**Décision** : Les 4 fichiers de test (`rules.test.ts`, `useGridGestures.test.ts`, `useLevel.test.ts`, `generator.test.ts`) supprimés ; `vitest`, `@testing-library/react` et `jsdom` désinstallés ; script `test` retiré de `package.json`.

**Pourquoi** : Baptiste : les tests ralentissent le développement au lieu de l'améliorer. Reversement direct de [BDR-037](BDR-037.md), qui avait explicitement conservé cette infra après une demande de retrait refusée le même jour.

**Alternatives considérées** : Garder l'infra mais arrêter d'ajouter des tests — pas proposé, la demande était un retrait complet et explicite.
