# BDR-027 — Pas de vérification navigateur automatique sur ce projet, `agent-browser` non fonctionnel dans ce sandbox

**Décision** : Ne pas lancer de vérification UI automatisée via `agent-browser` sur ce projet, même quand le protocole général (CLAUDE.md) la recommande pour un changement visuel — s'appuyer sur lint/build/test verts et laisser Baptiste vérifier manuellement dans le navigateur.

**Pourquoi** : Préférence déjà actée le 2026-07-24 ("je m'occupe de regarder à chaque fois"), non retrouvée cette session faute d'être indexée en décision (seulement en prose dans le journal). Renforcée cette session : `agent-browser open`/`doctor` restent bloqués indéfiniment (timeout, sortie vide) dans ce sandbox Windows, y compris en `--offline --quick`, sans diagnostic plus poussé après 2 tentatives.

**Alternatives considérées** : Tentative de vérification via `agent-browser` cette session — abandonnée après 2 échecs consécutifs (timeout sur `open`, puis sur `doctor`).
