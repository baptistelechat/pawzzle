# BDR-041 — Verrou anti-scroll définitif sur `html`/`body`/`#root`

| Décision                                                                                                                                                                                                                                                                                                                                                                                        | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Alternatives considérées                                                                                                                                                                                                                     | Statut |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `html, body, #root { height: 100%; }` + `overflow: hidden; overscroll-behavior: none;` sur `html`/`body` dans `index.css`. Racine d'`App.tsx` en `h-full overflow-hidden` (au lieu de `h-dvh`). Budget de grille restauré à l'identique du commit `21c5551` (`calc(100dvh-19rem-env(safe-area-inset-top)-env(safe-area-inset-bottom))`, `viewport-fit=cover`, padding safe-area sur le footer). | [BDR-040](../decisions/BDR-040.md) garantissait "zéro scroll" via `overflow-hidden` sur un `<div>` descendant — faux en pratique : si ce div (`h-dvh`) calcule une hauteur supérieure à l'espace visible (constaté en PWA), `body` n'étant lui-même pas contraint devient scrollable pour le contenir ([BLK-034](../blockers/BLK-034.md)). Verrouiller `html`/`body` directement rend la garantie indépendante de tout calcul `dvh`, fiable ou non. Baptiste a identifié via `git log`/`git diff` que le commit `21c5551` (budget safe-area) était la version la moins pire testée jusque-là — restauré tel quel comme base plutôt que de repartir d'une nouvelle hypothèse. | `h-dvh overflow-hidden` sur un div descendant (BDR-040, remplacé) : insuffisant, voir ci-dessus. Contraindre uniquement via un budget par élément (BDR-039, remplacé) : fragile, ne couvre pas le vrai problème (scroll au niveau document). | actif  |

Un second bug est apparu immédiatement après ce verrou : `#root` manquait dans la chaîne `height:100%`, donc `h-full` posé sur la racine d'`App.tsx` retombait sur la taille du contenu au lieu de remplir l'écran, laissant un vide visuel en bas ([BLK-035](../blockers/BLK-035.md)). Ajouté à la chaîne, résolu.
