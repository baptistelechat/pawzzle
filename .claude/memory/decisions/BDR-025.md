# BDR-025 — Panneaux Réglages/Règles : Dialog + store singleton calqué sur le pattern ambiant

| Décision                                                                                                                                                                                                                                                                                                                                                                                          | Pourquoi                                                                                                                                                                                                                                                                                                   | Alternatives considérées                                                                                                                                                                            | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Deux nouveaux panneaux (`SettingsDialog`, `RulesDialog`) implémentés en `Dialog` (base-ui, pas de `Sheet`) ; état audio/vibration centralisé dans `src/lib/settings.ts`, un singleton + `useSyncExternalStore` persistant en `localStorage`, calqué sur le pattern déjà en place pour le lecteur ambiant ([BDR-017](BDR-017.md), [BDR-021](BDR-021.md)) plutôt qu'une nouvelle dépendance d'état. | Cohérence avec l'architecture existante (pas de dossier `stores/`, pas de zustand). `Dialog` plus simple à mettre en page pour les 3 visuels de règles côte à côte qu'un `Sheet` (tiroir bas) ; le `docs/ROADMAP.md` notait déjà l'abandon d'un `Popover` pour un réglage similaire sur l'`AmbientPlayer`. | `Sheet` (tiroir bas, pattern mobile plus habituel) — écarté, Baptiste a tranché pour `Dialog` après question directe. Store zustand — écarté, un singleton suffit et évite une nouvelle dépendance. | actif  |
