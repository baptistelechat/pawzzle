# BDR-20261027165040-4 — Soft launch `1.0.0-beta.1` avant Supabase et la landing page

**Décision** : Publier une bêta partageable à l'entourage dès la fin de la Phase 4.1, sans attendre la Phase 4.2 (auth + sauvegarde Supabase) ni la 4.3 (LP/SEO). La bêta comprend : PWA hors-ligne (SFX précachés, ambiance exclue), og:image + meta de partage, crédits audio dans Réglages, analytics PostHog. Version `1.0.0-beta.1`, déploiement depuis `main` (`pawzzle-game.vercel.app`).

**Pourquoi** : Le jeu est jouable sans compte, la progression tient en `localStorage` ; Supabase sert surtout la synchro cross-device, pas la validation du gameplay. Le retest de la 4.1 (forme + taille aléatoires) prévu par la roadmap demande de vrais joueurs, et l'analytics mesure l'adoption avant d'investir dans le backend.

**Alternatives considérées** : Suivre la roadmap complète (4.2 + 4.3) avant toute diffusion — écartée, plusieurs sessions de dev sans aucun retour utilisateur réel.
