# BDR-20260730065326-4 — Toggles son/vibration + Règles dupliqués sur l'accueil

**Décision** : Les 3 toggles (Vibrations/Sons/Ambiance) et le bouton Règles sont dupliqués directement sur l'écran d'accueil, sous les cartes de mode — pas seulement accessibles via le dialog Réglages en jeu. Extraits en composants partagés (`IconToggle`, `SoundHapticsToggles`) réutilisés par `SettingsDialog` et l'accueil.

**Pourquoi** : Demande de Baptiste — accès rapide aux réglages ambiants et aux règles avant même de choisir un mode, sans ouvrir de dialog.

**Alternatives considérées** : Aucune envisagée, demande directe.
