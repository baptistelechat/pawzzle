# BDR-20260730065326-3 — Pause du chrono étendue à Réglages/Règles

| Décision                                                                                                                                                                               | Pourquoi                                                                                                                                  | Alternatives considérées                                                                                  | Statut |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ------ |
| Le chrono de la run se met en pause non seulement pendant l'AlertDialog de confirmation d'abandon, mais aussi pendant que les dialogs Réglages ou Règles sont ouverts en cours de run. | Consulter un menu pendant une run Chrono ne doit pas coûter du temps de jeu — même logique d'équité que la pause pendant la confirmation. | Pause limitée à la seule AlertDialog de confirmation (portée initiale) — jugée insuffisante par Baptiste. | actif  |
