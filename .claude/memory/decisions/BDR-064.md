# BDR-064 — Badge de difficulté visible seulement en status "playing"

| Décision                                                                                                                                                                                                                                 | Pourquoi                                                                                                                                                                                                      | Alternatives considérées                                                                                                                                        | Statut |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `DifficultyBadge` est inséré dans la rangée `PawCounter`/`HeartsRow` de `App.tsx`, qui n'est rendue que pendant `status === "playing"` — le badge disparaît donc pendant won/lost, en même temps que le compteur de pattes et les cœurs. | Réutilise l'emplacement et le pattern déjà en place (même rangée, même conditionnement), zéro code de layout supplémentaire. Choix d'implémentation par défaut, pas encore explicitement validé par Baptiste. | Badge toujours visible (y compris won/lost), pour comparaison après-coup — écarté par défaut faute de demande explicite, à reconsidérer si Baptiste le signale. | actif  |
