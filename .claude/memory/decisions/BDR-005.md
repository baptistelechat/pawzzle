# BDR-005 — Plugins Vite DX sandbox : qrcode, checker, mkcert, visualizer

**Décision** : Ajout de `vite-plugin-qrcode`, `vite-plugin-checker`, `vite-plugin-mkcert`, `rollup-plugin-visualizer` (activé via `pnpm build:analyze`, mode Vite natif — voir GLRN-211)

**Pourquoi** : Pawzzle sert de bac à sable pour tester des plugins DX avant de les généraliser à d'autres projets ; ces 4 plugins n'impactent que le dev/build local, aucun impact bundle production

**Alternatives considérées** : `unplugin-turbo-console` (retiré, voir [ZBLK-003](../archive/blockers/ZBLK-003.md)), `unplugin-icons`, `vite-plugin-pwa` (prématuré, réservé Phase 4), `vite-plugin-inspect` (reporté, pas de besoin immédiat)
