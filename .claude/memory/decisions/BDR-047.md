# BDR-047 — Pincer-zoomer bloqué via `touch-action: pan-x pan-y`, pas via la meta viewport

| Décision                                      | Pourquoi                                                                                                                                                                                                                                          | Alternatives considérées                                                                                                                                                                                                                                          | Statut |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `touch-action: pan-x pan-y;` posé sur `html`. | Bloque le pincer-zoomer (gênant pendant le jeu) sans désactiver le zoom natif d'accessibilité pour les malvoyants — `user-scalable=no` dans la meta viewport casse WCAG 1.4.4 pour tout le monde. Testé et confirmé suffisant sur Android Chrome. | `maximum-scale=1, user-scalable=no` dans la meta viewport (écarté, coût a11y trop élevé pour un problème pas confirmé sur iOS). `touch-action: manipulation` (écarté, autorise encore le pincer-zoomer — seul le double-tap-zoom est désactivé par cette valeur). | actif  |
