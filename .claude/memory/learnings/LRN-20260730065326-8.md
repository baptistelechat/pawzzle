# LRN-20260730065326-8 — `margin-top` scopé + `gap` de flex parent partagé s'additionnent silencieusement

| Pattern observé                                                                                                                                                                                                                                      | Contexte                                                                                                                                                                                                                                                 | Application future                                                                                                                                                                                                                                                                                                                               |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Ajouter un `mt-*` sur UN enfant d'un flex container qui a déjà un `gap-*` entre ses enfants fait s'additionner les deux valeurs pour CET écart précis, cassant l'égalité recherchée avec les autres écarts du même flex qui n'ont que le `gap` seul. | `mt-4` ajouté sur le wrapper "mode-select" pour l'écarter du titre s'additionnait au `gap-4` du parent partagé avec l'écran de jeu (32px vs 16px pour l'écart suivant) — repéré par Baptiste via une comparaison visuelle directe entre les deux écarts. | Pour égaliser un écart scopé à une seule branche conditionnelle sans toucher au `gap` partagé (qui peut avoir d'autres contraintes ailleurs, ex. un budget de hauteur), soit appliquer la marge scopée ET augmenter le gap interne de la branche pour qu'ils totalisent la même valeur, soit sortir totalement l'écart du système `gap` partagé. |
