# LRN-021 — vitest sans jsdom : un import transitif à effet de bord navigateur casse un test sans rapport apparent

| Pattern observé                                                                                                                                                                                                                                                                                                                            | Contexte                                                                                                                                                                                                                                                                                    | Application future                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un test qui importe un module A (ex: un store de settings) échoue si A importe, même indirectement, un module B qui exécute du code touchant une API navigateur (`new Audio()`, `window`, etc.) au niveau module — pas dans une fonction. L'erreur ne pointe pas vers le vrai fichier fautif, juste vers l'import qui déclenche la chaîne. | Tentative d'ajouter un test unitaire pour `settings.ts` (Pawzzle), qui importe `sounds.ts` — celui-ci fait `const ambient = new Audio()` en haut de fichier. Crash immédiat en environnement Node pur (pas de jsdom configuré dans ce projet, `vitest` tourne en environnement par défaut). | Avant d'écrire un test pour un module, vérifier toute la chaîne d'imports pour du code à effet de bord au niveau module, pas seulement le fichier testé directement. Si l'environnement de test n'a pas de DOM (jsdom/happy-dom absent), soit ajouter cette dépendance si le besoin se répète, soit s'appuyer sur une vérification manuelle plutôt que de forcer un test qui nécessite une infra absente. |
