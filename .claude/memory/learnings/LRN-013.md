# LRN-013 — CSS `corner-shape:squircle` + rayon en `%` = squircle progressive-enhancement sans lib

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Contexte                                                                                                | Application future                                                                                                                                                                                                                                                           |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| La propriété CSS `corner-shape: squircle` (superellipse, style icônes iOS) transforme la courbe des coins définis par `border-radius`, mais support Chrome/Edge 139+ uniquement à date (Safari/Firefox non supportés — dégradation propre en rectangle simplement arrondi). Elle nécessite toujours un `border-radius` non nul pour avoir un effet visible. Utiliser un rayon en **pourcentage** (`rounded-[28%]`) plutôt qu'une valeur fixe (rem/px token) rend le rendu proportionnel à la taille réelle de l'élément — cohérent quelle que soit sa taille (grille dynamique, responsive). | Pawzzle — cases de grille de puzzle ([BDR-014](../decisions/BDR-014.md)), direction "Atelier Feutrine". | `rounded-[28%] [corner-shape:squircle]` (Tailwind v4, arbitrary property) donne un vrai squircle sur Chromium et un rectangle généreusement arrondi ailleurs — zéro lib/JS/canvas nécessaire. Vérifier le support navigateur cible avant de compter sur `corner-shape` seul. |
