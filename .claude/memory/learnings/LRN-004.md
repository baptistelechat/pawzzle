# LRN-004 — Contraste WCAG : `*-foreground` blanc échoue souvent sur une couleur de marque vive

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                               | Contexte                                                                                                                                                                                                       | Application future                                                                                                                                                                                                                                                                                |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Assigner naïvement blanc (`#ffffff`) comme `*-foreground` (`primary-foreground`, `accent-foreground`) sur une couleur de marque pastel/vive de luminance moyenne (corail `#ff8a65`, sauge `#7fb894`) produit un ratio de contraste ~2.3:1, sous le seuil AA (4.5:1 texte normal, 3:1 large). Le foreground sombre déjà défini pour le corps de texte (`#4a3728`) passe à ~4.9:1 sur les mêmes couleurs, sans changer le fond. | Application de la direction de branding "Atelier Feutrine" (shadcn, palette Pawzzle) — le blanc convenait au logo/gros icône (pas soumis aux mêmes règles) mais pas au texte réel des boutons/badges de l'app. | Avant d'assigner un `*-foreground` blanc sur une couleur de marque de luminance moyenne, vérifier le ratio (`(max(L1,L2)+0.05)/(min(L1,L2)+0.05)`) ou tester directement — le foreground sombre déjà défini pour le corps de texte est presque toujours un choix plus sûr sur ce type de couleur. |
