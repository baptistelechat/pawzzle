# LRN-017 — Générer un manifest au build plutôt que coder en dur une liste de fichiers `public/` évolutive

| Pattern observé                                                                                                                                                                                                                                                                                                                        | Contexte                                                                                                                                                                                                | Application future                                                                                                                                                                                                                                                |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Quand une liste de fichiers statiques (dossier `public/`) doit être connue côté client sans être bundlée par Vite, générer un fichier manifest (JSON) au moment d'un script d'outillage/build plutôt que maintenir un tableau codé en dur dans le code source — évite la resynchronisation manuelle à chaque ajout/retrait de fichier. | Playlist de sons d'ambiance (Pawzzle) — un tableau `AMBIENT_TRACKS` codé en dur aurait nécessité une édition de `sounds.ts` à chaque nouvelle piste déposée par Baptiste dans `public/sounds/ambient/`. | Réutilisable pour toute liste de fichiers `public/` devant être connue au runtime sans bundling (images, sons, données) : un script Node scanne le dossier réel et écrit `manifest.json`, le client `fetch()` ce manifest au lieu d'une liste figée dans le code. |
