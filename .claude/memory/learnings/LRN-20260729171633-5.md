# LRN-20260729171633-5 — Un libellé de bouton réutilisé à une échelle plus large devient ambigu

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                           | Contexte                                                                                                                                                                                                                      | Application future                                                                                                                                                                                                                                                                                                                 |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Le bouton "Nouvelle partie" désignait sans ambiguïté "régénérer le niveau courant" en mode Classique (aucune conséquence, action locale). Une fois les modes Chrono/Endurance introduits (notion de run multi-niveaux), le même libellé/action devenait dangereusement ambigu : Baptiste a dû signaler explicitement qu'il fallait avertir de la perte de toute la run avant de relancer. | Le bug n'est apparu qu'après l'ajout d'une notion de portée plus large (la run) au-dessus d'une action existante (le niveau) — l'action elle-même n'avait pas changé de code, seul son contexte d'usage avait changé de sens. | Quand une fonctionnalité introduit une portée plus large au-dessus d'une action existante (item → collection, niveau → run, brouillon → publication...), auditer explicitement chaque bouton/libellé réutilisé pour vérifier si son sens implicite a changé — pas seulement écrire le nouveau code, avant de le livrer sans guard. |
