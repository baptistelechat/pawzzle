# LRN-043 — Pooler des sous-groupes dans un seuillage crée un biais mesurable

| Pattern observé                                                                                                                                                                                                                                               | Contexte                                                                                                                                                                                                                                                                    | Application future                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Fusionner plusieurs sous-catégories dans un seuillage statistique partagé (quartiles communs) n'est pas neutre : chaque sous-groupe se répartit différemment dans les buckets résultants selon que sa propre distribution est décalée par rapport aux autres. | Seuils de difficulté carré+cercle mélangés par taille : à 10×10, un carré atterrit "Extrême" 33% du temps contre 17% pour un cercle (idéal neutre 25/25 si le mélange était sans effet) — les carrés ont un score structurellement plus élevé, tirant le pool vers le haut. | Avant de pooler des sous-populations dans un seuillage partagé, mesurer la répartition réelle de chaque sous-groupe dans les buckets résultants (comparer à la répartition idéale équilibrée) plutôt que supposer la neutralité du mélange — si le biais est jugé acceptable, le documenter explicitement comme un compromis assumé, pas un oubli. |
