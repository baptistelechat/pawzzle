# LRN-024 — Corriger la stale closure sur UN état ne suffit pas si le handler en touche plusieurs

| Pattern observé                                                                                                                                                                                                              | Contexte                                                                                                                                                                                                                                                                                    | Application future                                                                                                                                                                                                                 |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dans un handler React déclenché par des sources concurrentes (multi-touch, timers), une race condition corrigée sur UN état peut laisser un état voisin lu-puis-écrit dans le même handler exposé à exactement la même race. | `togglePaw` lisait `errors` ET `placed` par closure. Un premier fix (ref mirror sur `errors`) a semblé complet — revue de code + test manuel simple validés — mais un test multi-touch réel (deux doigts, même case) a révélé que `placed` avait la même faille dans sa garde anti-doublon. | Quand une race condition apparaît sur un état donné, auditer systématiquement tous les autres states lus-puis-écrits dans le même handler avant de considérer le fix complet — pas seulement celui identifié par le premier repro. |
