# LRN-010 — Plusieurs `useWebHaptics()` indépendants pilotent le même `navigator.vibrate()` global → patterns qui s'écrasent

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Contexte                                                                                                                                                                                                                            | Application future                                                                                                                                                                                                                                                                                                                 |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `useWebHaptics()` appelé séparément dans 3 composants (`useLevel`, `App`, `Nav`) crée 3 instances `WebHaptics` indépendantes, chacune avec son propre minuteur/rAF interne pour dérouler un pattern multi-étapes — mais toutes pilotent le **même** `navigator.vibrate()` global du navigateur. Signalé par Baptiste : "les vibrations ne sont pas toujours jouées". Une instance ne sait pas qu'une autre est en train de dérouler son propre pattern ; leurs appels `navigator.vibrate()` s'entrelacent et se coupent mutuellement dès que deux actions (ex. poser un pion + toggle Aide) tombent proches dans le temps. | Pawzzle — Phase 4 haptics (plan 006). Fix : instance unique `new WebHaptics()` exportée en singleton module (`src/lib/haptics.ts`), consommée directement (pas de hook) par les 3 composants, éliminant toute instance concurrente. | Toute lib qui pilote une **ressource globale du navigateur** (vibration, audio, wake lock, notifications) ne doit avoir qu'**une seule instance vivante** dans l'app, même si son API se présente comme un hook React réutilisable partout — un hook par composant n'implique pas un état isolé si l'API sous-jacente est globale. |
