# LRN-20260730065326-9 — Wrapper flex sans largeur explicite casse un `w-full` descendant dans un `items-center`

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Contexte                                                                                                                                                                                                                                                                                                                              | Application future                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Envelopper un élément `width:100%` (Tailwind `w-full`) dans un NOUVEAU wrapper div sans largeur explicite, à l'intérieur d'un flex container `items-center` (align-items != stretch), casse silencieusement la résolution du pourcentage — le wrapper (flex item sans largeur déclarée) se réduit à son contenu (shrink-to-fit) au lieu de s'étirer, et le `w-full` de l'enfant se résout contre CE wrapper rétréci plutôt que contre l'espace réel disponible. Aucune classe CSS du composant enfant n'a besoin de changer pour que son rendu se rétrécisse. | Un wrapper `motion.div` (sans className) ajouté autour de `GameScreen`/`ModeSelect` dans `App.tsx` pour leur donner une transition d'entrée/sortie a fait rétrécir toute la colonne de jeu sur mobile — diagnostic initial erroné (attribué à la forme "cercle" du niveau) avant qu'une comparaison `git diff` révèle la vraie cause. | Tout nouveau wrapper inséré entre un flex container `items-center` et un enfant `w-full`/`max-w-*` doit recevoir explicitement `w-full` (ou `flex-1`/`self-stretch`) — et si l'enfant doit rester centré quand son propre `max-width` le rétrécit sous la largeur du wrapper, reprendre EXACTEMENT le pattern de centrage (axe/direction) de l'ancien parent direct plutôt que d'en inventer un nouveau non testé (ex: `flex-col items-center` ≠ `flex justify-center` en row). |
