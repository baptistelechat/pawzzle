# LRN-023 — Base UI Dialog autofocus le premier élément focusable, même sans clavier

| Pattern observé                                                                                                                                                                                                                            | Contexte                                                                                                                                                               | Application future                                                                                                                                                                                                                                                                                   |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un `Dialog` Base UI déplace le focus vers le premier élément focusable de son contenu à l'ouverture — ce qui déclenche un anneau `focus-visible` visible même quand l'utilisateur a ouvert la modal à la souris/au tactile, pas au clavier | `WelcomeDialog` n'a qu'un seul élément focusable (le bouton "C'est parti !") : il recevait systématiquement un anneau de focus au premier affichage, jugé inesthétique | Passer `initialFocus={false}` sur `DialogContent`/`DialogPopup` pour laisser le focus sur le conteneur du popup (déjà stylé `outline-none` dans `ui/dialog.tsx`) plutôt que sur le premier élément interactif — à réutiliser pour toute modal avec un unique bouton d'action visible dès l'ouverture |
