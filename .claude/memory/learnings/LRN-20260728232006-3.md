# LRN-20260728232006-3 — `position:absolute` sans z-index déclaré passe derrière un sibling z-index explicite

| Pattern observé                                                                                                                                                                                                                                                                  | Contexte                                                                                                                                                                                | Application future                                                                                                                                                                                                                                                                                                                                        |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un logo en `position:absolute; bottom:90px` sans `z-index` déclaré (donc `z-index:auto`) se retrouvait rendu derrière les cellules de la grille (`.cell { z-index:1 }`), alors que le logo venait plus tard dans le DOM — seul un fragment visible dans les gaps entre cellules. | Génération d'un carrousel Instagram statique (slide CTA final) : grille avec cellules explicitement stackées (`z-index:1`) + logo positionné en absolu par-dessus, sans z-index propre. | Un élément positionné qui doit apparaître au-dessus d'un sibling à z-index explicite a besoin lui-même d'un z-index explicite — l'ordre DOM seul ne suffit pas dès qu'un des deux éléments a `z-index` déclaré. Sinon, préférer le flux normal (flex/grid, `margin-top`) plutôt que `position:absolute` quand aucun chevauchement n'est réellement voulu. |
