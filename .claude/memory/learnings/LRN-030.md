# LRN-030 — `snap-always` empêche un swipe rapide de sauter plusieurs cartes

| Pattern observé                                                                                                                                                                                                                                                                                                                               | Contexte                                                                                                                                                                                                                                        | Application future                                                                                                                                                                                                     |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un carrousel en `overflow-x-auto` + `snap-x snap-mandatory` snappe correctement sur un swipe lent, mais un swipe rapide/fling peut traverser plusieurs cartes avant que le navigateur ne stoppe — sans `scroll-snap-stop: always` (Tailwind : `snap-always`), le point d'ancrage n'est garanti qu'en fin de décélération, pas à chaque geste. | Baptiste a signalé que le swipe mobile sur le carrousel de règles avançait de plusieurs cartes selon la vitesse au lieu d'une seule à la fois. Ajout de `snap-always` sur chaque carte (`section`) a résolu le symptôme immédiatement, sans JS. | Dès qu'un carrousel/pagination CSS natif doit garantir "une carte par geste" (pas de free-scroll multi-page), poser `snap-always` sur les enfants dès la première implémentation plutôt que d'attendre le signalement. |
