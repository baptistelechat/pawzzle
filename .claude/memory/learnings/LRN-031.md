# LRN-031 — Simuler un swipe/drag/wheel via CDP headless est peu fiable, même via dispatch DOM direct

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                    | Contexte                                                                                                                                                                                                                                                                                                        | Application future                                                                                                                                                                                                                                                |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Trois approches distinctes pour simuler un geste de scroll (`agent-browser mouse wheel`, `agent-browser mouse move/down/up` en séquence, dispatch d'un `MouseEvent` natif via `eval` directement sur l'élément) ont toutes échoué à déclencher de façon fiable le comportement attendu (scroll horizontal, handler `onMouseDown` React) — sans message d'erreur explicite, juste un état inchangé ou incohérent selon le timing des commandes CDP. | Vérification du swipe tactile (session précédente) puis du drag souris desktop (cette session) sur le carrousel de règles. Les deux tentatives ont été abandonnées après 2+ essais chacune ([ZBLK-036](../archive/blockers/ZBLK-036.md)), au profit d'une relecture de code + demande de vérification manuelle. | Ne pas s'obstiner à automatiser la vérification d'un geste de scroll/drag/swipe dans ce sandbox — accepter la relecture de code (pattern standard, lint/build verts) comme validation suffisante, et déléguer la confirmation du geste lui-même à un test manuel. |
