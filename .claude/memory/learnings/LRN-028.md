# LRN-028 — Certificat mkcert non approuvé sur le téléphone bloque l'installabilité PWA

| Pattern observé                                                                                                                                                                                                                               | Contexte                                                                                                                                                                                                        | Application future                                                                                                                                                                                                                                                                                                                                                                                               |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `beforeinstallprompt` ne se déclenche jamais sur Android Chrome même avec manifest, icônes, SW et `display: standalone` tous corrects, si la page est servie via un certificat mkcert dont la CA locale n'est installée que sur le PC de dev. | Test de l'installation PWA sur `https://<ip-lan>:4173` (vite preview --host) depuis un téléphone Android : la page charge (après bypass de l'avertissement), mais aucune proposition d'installation n'apparaît. | Devant une PWA qui ne se propose pas à l'installation, vérifier d'abord si l'origine est servie par un certificat que le téléphone reconnaît comme valide (localhost et domaines avec cert public type Vercel/Let's Encrypt sont OK, mkcert local ne l'est pas sur un autre appareil) avant de suspecter le manifest ou le service worker. Fix rapide : tester via l'URL de déploiement Vercel plutôt qu'en LAN. |

Sur iPhone Safari, `beforeinstallprompt` n'existe pas du tout — l'app bascule déjà sur une astuce « Partager > Sur l'écran d'accueil » ([InstallButton](../../../src/components/InstallButton/index.tsx)), ce n'est pas un bug si rien ne s'affiche nativement.
