# LRN-20260730065326-7 — Largeur réservée doit se baser sur la donnée réelle de l'instance

| Pattern observé                                                                                                                                                                                                                                                                                                                                    | Contexte                                                                                                                                                                                                                                                             | Application future                                                                                                                                                                                                                                                                                                                  |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Réserver la largeur d'un compteur (icône+chiffres) sur le pire cas GLOBAL possible (ex. "10/10") plutôt que sur la plage réelle de CE composant (le `total` d'un niveau, fixe pour toute sa durée de vie) crée un mou visuel systématique dans les cas courants — visible dès que le composant est entouré d'autres éléments dans une même rangée. | `PawCounter` réservait `calc(1rem+0.25rem+5ch)` pour tous les niveaux, même 6×6/8×8 où `total` ne dépasse jamais 1 chiffre — l'écart avec `HeartsRow` restait visiblement plus large que les autres gaps de la rangée malgré un premier correctif (`justify-start`). | Quand une largeur doit être réservée pour éviter un jump (digit count qui varie), calculer le pire cas à partir des VRAIES bornes de la donnée pour CETTE instance (ex. `String(total).length`), pas d'une constante globale — surtout si le composant est remonté à chaque changement de donnée (ici via sa clé `paw-${levelId}`). |
