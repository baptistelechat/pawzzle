# LRN-025 — Symptôme réparé par une rotation d'écran = layout, jamais état

| Pattern observé                                                                                                                                                                                                                         | Contexte                                                                                                                                                                                            | Application future                                                                                                                                                                                                                                                                                                        |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Si rien dans l'app ne re-render sur un changement d'orientation, un élément qui « apparaît » après rotation était déjà monté avec ses données. La rotation n'agit alors que sur le viewport et le flux CSS — donc le bug est un layout. | La pill du lecteur ambiant était signalée absente en prod mobile, mais réapparaissait après un aller-retour paysage → portrait. Le réflexe initial pointait vers une notification de store manquée. | Avant de suspecter un `useSyncExternalStore`, un fetch ou un abonnement, lister ce qui re-render sur rotation. Si la réponse est « rien », couper court : la donnée est là, chercher pourquoi l'élément n'est pas visible (contenu plus haut que le viewport, barre d'URL déployée, `dvh` recalculé, ancêtre `overflow`). |

Corollaire pratique : un layout « qui tient juste » sur un écran de référence ne tient pas quand la barre d'URL mobile est déployée (≈ 60 px de moins). Un contrôle qui doit rester atteignable ne doit pas dépendre du fait que le contenu rentre.
