# LRN-20260727233635-5 — HyperFrames `autoProxy` : tuer un rendu en plein vol peut supprimer les assets sources sans les régénérer

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                   | Contexte                                                                                                                                                                                                                                                                                             | Application future |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| `assets/paw_correct.mp3` et `assets/paw_incorrect.mp3` ont disparu du disque entre deux commandes HyperFrames (lint/check propres, puis render échoué avec `audio_src_not_found`) — corrélé avec un process de render précédent tué en pleine exécution sur un projet avec `media.autoProxy: true` dans `hyperframes.json`. Mécanisme exact non confirmé, mais restauration réussie depuis la source d'origine externe au projet vidéo (`public/sounds/` du jeu). | Éviter de force-kill un process `hyperframes render`/`check` en cours d'exécution sur un projet `autoProxy: true`. Si un asset source disparaît après un kill, vérifier d'abord une source de vérité externe (repo d'origine, copie amont) avant de re-générer ou de considérer la perte définitive. |
