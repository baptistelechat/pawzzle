# LRN-20260727233635-4 — HyperFrames : rendre un fichier `<template>` sous-composition via `-c` échoue (zero duration)

| Pattern observé                                                                                                                                                                                                                                                                                                                                  | Contexte                                                                                                                                                                                                                                                                   | Application future |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| `npx hyperframes render -c compositions/scene4.html` (sous-composition avec wrapper `<template>`, prévue pour être montée via `data-composition-src`) échoue avec « Composition has zero duration » / « No GSAP timeline registered » — le composant ne s'enregistre correctement sur `window.__timelines` que lorsqu'il est monté par son hôte. | Pour vérifier/rendre une sous-composition isolément, passer par le composition hôte (`index.html` complet) plutôt que `-c` directement sur le fichier `<template>` — celui-ci n'a pas de racine autonome (`data-start`, timeline enregistrée) hors du contexte de montage. |
