# LRN-20260728232006-4 — `$(pwd)` en Git Bash ≠ chemin attendu par un sous-process Node pour une URL file:// sur Windows

| Pattern observé                                                                                                                                                                                                                                                                                                             | Contexte                                                                                                                                                  | Application future                                                                                                                                                                                                                                                                        |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `agent-browser open file:///$(pwd)/fichier.html` a échoué avec `net::ERR_FILE_NOT_FOUND` dans une boucle isolée, alors que le même pattern avec `$(pwd -W \|\| pwd)` fonctionnait juste avant — `$(pwd)` nu peut renvoyer un chemin POSIX (`/c/Users/...`) au lieu du chemin Windows attendu pour une navigation `file://`. | Génération d'un carrousel Instagram : boucle de screenshot `agent-browser` sur 6 fichiers HTML locaux, plusieurs commandes séparées dans la même session. | Toujours résoudre le chemin en `pwd -W` (ou `cygpath -w`) avant de construire une URL `file://` ou tout chemin transmis à un sous-process Node depuis Git Bash sur Windows — ne jamais supposer que `$(pwd)` seul suffit, même si ça a fonctionné une fois plus tôt dans la même session. |
