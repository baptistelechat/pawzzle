# LRN-20260727233635-2 — Prouver l'absence d'un cue audio : rendu réel + ffmpeg + contrôle positif, pas juste lint/grep

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Contexte                                                                                                                                                                                                                                                                                                                                                                         | Application future |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| L'utilisateur signalait entendre un son au moment précis d'un beat visuel (glow/X, scene4) alors que `grep`/`npx hyperframes lint`/`check` montraient un code propre (un agent précédent s'était arrêté à cette vérification). Rendu réel (draft puis final) + analyse `ffmpeg astats` (peak level, fenêtre 10ms) sur la piste audio composée ont confirmé l'absence de tout cue distinct dans la fenêtre visée — la méthode a été validée en la testant d'abord sur deux vrais SFX connus ailleurs dans la vidéo (contrôles positifs), qui produisent un pic net et isolé de ~9dB, absent de la fenêtre suspecte. | Quand un rapport utilisateur contredit une vérification statique (code, lint, grep), rendre l'artefact réel et analyser le signal produit plutôt que de se fier au code seul. Valider la sensibilité de sa propre méthode de mesure avec un cas positif connu avant de conclure à une absence — sans quoi une méthode insensible confirmerait à tort n'importe quelle hypothèse. |
