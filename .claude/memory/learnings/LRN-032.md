# LRN-032 — "Voir X depuis n'importe où" = élément fixe, pas une carte de plus dans le carrousel

| Pattern observé                                                                                                                                                                                                                                                                                                                        | Contexte                                                                                                                                                                                                | Application future                                                                                                                                                                                                                         |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Une demande formulée "ainsi on voit aussi X de n'importe où" dans le contexte d'un carrousel/pagination a été interprétée comme "X devient une carte supplémentaire du carrousel" — lecture plausible mais fausse. Le sens réel : X doit rester visible en permanence, indépendamment de la navigation, donc hors du composant paginé. | Carrousel de règles : "Comment jouer" avait été mis en 4ème carte swipeable ; Baptiste a corrigé — il voulait une section fixe sous le carrousel, toujours affichée, quelle que soit la règle en cours. | Quand une demande mélange "carrousel/pagination" et "voir de n'importe où"/"toujours visible", présumer un élément FIXE en dehors du composant paginé plutôt qu'une carte de plus — ou clarifier avant d'implémenter si le doute persiste. |
