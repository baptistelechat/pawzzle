# LRN-002 — Grille 3×3 mathématiquement insoluble pour un puzzle Queens-like

| Pattern observé                                                                                                                                                                                                                                                                                  | Contexte                                                                                                                                                                                   | Application future                                                                                                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Avec la règle d'adjacence 8 voisins, aucune permutation de colonnes ne peut satisfaire une grille 3×3 : pour 3 colonnes {0,1,2}, deux écarts consécutifs ≥2 sont impossibles (seul l'écart 0↔2 vaut 2, et il ne peut pas se répéter sur 2 transitions consécutives sans réutiliser une colonne). | Découvert en écrivant un fixture de test 3×3 pour `isSolved` — la solution "évidente" plaçait systématiquement deux animaux adjacents en diagonale, quelle que soit la permutation testée. | Ne jamais utiliser `size < 4` (et size=4 reste très contraint) comme fixture de test ou taille par défaut pour un moteur Queens-like avec contrainte d'adjacence 8 voisins — pertinent aussi pour la taille minimale à proposer en Phase 2 côté UI. |
