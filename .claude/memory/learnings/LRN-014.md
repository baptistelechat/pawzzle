# LRN-014 — Debug d'animation invisible/mal timée : instrumenter le DOM en direct, ne pas deviner depuis le code

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                     | Contexte                                                                                                                                                                                                                                        | Application future                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Une animation "invisible" ou "qui se joue en même temps qu'une autre" ne se diagnostique pas de façon fiable par lecture de code (mécanismes d'`AnimatePresence`/transitions/timing async trop subtils) ni par `sleep()` + `screenshot` (latence de dispatch des outils CLI trop grande/imprévisible face à des animations de quelques centaines de ms — un screenshot pris "300ms après le clic" peut arriver après 1-2s de latence outil réelle). | Pawzzle — a permis de découvrir que l'animation de sortie de grille ne jouait jamais du tout (0 mutation DOM), contrairement à l'hypothèse initiale ("elle joue en même temps que l'entrée"), voir [ZBLK-009](../archive/blockers/ZBLK-009.md). | Injecter un script (`agent-browser eval`) qui échantillonne `getComputedStyle(el).opacity`/`.transform` en boucle `requestAnimationFrame`, horodaté via `performance.now()`, déclenché dans le MÊME appel JS que l'action (clic) pour éviter toute latence inter-commande — combiné à un `MutationObserver` pour confirmer si des nœuds DOM sont réellement ajoutés/retirés (pas juste mis à jour). Pour un timing "au tout premier chargement", utiliser un script d'init enregistré AVANT la navigation (`agent-browser --init-script`) plutôt que d'essayer de rattraper l'état après un `open`/`reload` classique — sinon la fenêtre d'observation est déjà passée. |
