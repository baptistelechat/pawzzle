# LRN-005 — Message de statut transitoire fusionné dans le même slot DOM

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Contexte                                                                                                                                                                                           | Application future                                                                                                                                                                                                                                                                          |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dans un layout `flex flex-col justify-center`, l'apparition d'un nouvel élément (message "Niveau réussi !" ajouté après une grille) change la hauteur totale du contenu, et `justify-center` re-centre alors toute la colonne — le contenu au-dessus (la grille) semble "sauter". Le fix root-cause : ne jamais ajouter/retirer d'élément mais remplacer le contenu texte d'un unique élément déjà présent (la ligne "Erreurs : X/3" devient "Niveau réussi !" au lieu qu'un nouveau `<p>` apparaisse en dessous). | Pawzzle — bug rapporté par Baptiste ("le message décale la grille"), reproduit et vérifié via mesure de bounding rect avant/après (agent-browser) : position identique au pixel près après le fix. | Pour tout indicateur de statut transitoire (succès/erreur/chargement) dans un conteneur centré verticalement, réserver un slot fixe unique et remplacer son contenu plutôt que d'ajouter un élément conditionnel — vérifier aussi si le `justify-center` du parent est lui-même nécessaire. |
