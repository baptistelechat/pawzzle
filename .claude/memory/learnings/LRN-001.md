# LRN-001 — MVP = clone strict avant toute innovation de gameplay

| Pattern observé                                                                                                                    | Contexte                                                                                                                                        | Application future                                                                                                                       |
| ---------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Le tout premier MVP est un clone volontairement sans innovation (grille carrée classique, 3 règles de base, aucune forme exotique) | Objectif : valider le moteur de règles et l'algorithme de génération sur le cas le plus simple avant d'ajouter complexité visuelle ou mécanique | Résister à l'envie d'ajouter des variantes de gameplay tant que le moteur de base + génération de niveaux ne sont pas validés et stables |
