# LRN-20260727233635-3 — Windows : `PATH` exporté en Bash invisible pour un sous-process npx/node — utiliser `$env:PATH` PowerShell

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                     | Contexte                                                                                                                                                                                                                                                                                                  | Application future |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| `ffmpeg`/`ffprobe` installés temporairement via npm (`ffmpeg-static`/`ffprobe-static`) dans un dossier scratch. `export PATH="$binDir:$PATH"` dans l'outil Bash ne suffisait pas pour que `npx hyperframes doctor`/`render` détecte les binaires (résolution PATH Windows côté sous-process natif). `$env:PATH = "$binDir;" + $env:PATH` dans PowerShell (séparateur `;`) fonctionnait immédiatement, confirmé par `doctor --json`. | Pour tout outil CLI Windows lancé en sous-process (npx, node) nécessitant un binaire hors PATH système, préférer l'ajout via PowerShell plutôt qu'un export Bash — le format de séparateur (`:` vs `;`) et la résolution PATH côté Windows natif ne sont pas garantis transparents entre les deux shells. |
