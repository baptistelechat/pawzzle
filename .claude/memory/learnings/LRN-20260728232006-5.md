# LRN-20260728232006-5 — Générer un asset marketing fidèle à la DA d'une app sans skill dédié

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                   | Contexte                                                                                                                                           | Application future                                                                                                                                                                                                                                                                                                                                    |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pour produire le carrousel Instagram "Comment on s'installe dans le village" sans installer de skill carrousel, un script Node a réutilisé directement les tokens réels du jeu (`REGION_COLORS`, classes squircle, palette Atelier Feutrine), généré 6 fichiers HTML statiques, puis `agent-browser` (déjà installé, outil de browser automation) a servi de moteur de capture (viewport 1080×1350) pour produire les PNG finaux. | Baptiste a demandé explicitement de produire le premier carrousel "sans skille" après avoir identifié `marcolang/instagram-carousel` en recherche. | Pour tout besoin "génère-moi un visuel/asset" sans skill dédié disponible ou souhaité : mini-générateur HTML réutilisant les vrais design tokens du projet + capture via un outil de browser automation déjà installé (`agent-browser` ou équivalent) — reproductible sur n'importe quel projet ayant déjà cet outil, sans dépendance supplémentaire. |
