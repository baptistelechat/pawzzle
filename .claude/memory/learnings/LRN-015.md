# LRN-015 — Distinguer tap et glisser par seuil de distance pixel, pas par franchissement de case/zone

| Pattern observé                                                                                                                                                                                                                                                                                                                  | Contexte                                                                                                                                                                   | Application future                                                                                                                                                                                                                                                                                                                      |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| La détection "changement de case/zone discrète" est un proxy trop grossier pour annuler un timer de geste continu (appui long) : un glisser lent peut rester dans la zone de départ plus longtemps que le délai visuel attendu, laissant l'indicateur flasher avant d'être annulé ([ZBLK-014](../archive/blockers/ZBLK-014.md)). | Grille interactive avec appui long ET glissement multi-cases sur les mêmes éléments (Pawzzle, `Grid.tsx`) — deux gestes distincts à partager depuis le même `pointerdown`. | Mesurer la distance euclidienne réelle du pointeur depuis son point de départ (`clientX/clientY` capturés au `pointerdown`), comparer à un seuil fixe (~10px, seuil tap/drag usuel des UI tactiles) — indépendant de toute logique de zone/case, donc réutilisable sur n'importe quelle UI pointeur devant distinguer tap/hold de drag. |
